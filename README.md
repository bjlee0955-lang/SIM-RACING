# 🏁 GT3 Circuit — 3D Sim Racing

브라우저에서 바로 즐기는 모바일 최적화 3D GT3 레이싱 게임입니다. **Three.js**로 만들어졌으며 외부 CDN 의존성 없이 동작합니다 (라이브러리가 저장소에 내장되어 있음).

폰을 좌우로 기울여 스티어링을 조작하는 **기울기 센서 조작**이 핵심 기능이며, 연료 무게와 타이어 마모가 실제로 주행에 영향을 주는 아케이드 시뮬레이션입니다.

## 주요 기능

- 🏎️ **GT3 차량 5종** 중 선택 (각기 다른 출력/그립/연비 스펙)
- 🛣️ **자체 제작 F1 스타일 서킷** (~3.1km, 실제 트랙을 그대로 재현한 것은 아님)
- 📱 **기울기 센서 스티어링** — 폰을 쥔 채로 좌우로 기울여서 조작 (센서 미지원 시 터치로 대체 가능)
- 🏁 **퀄리파잉(1랩) → 레이스(5랩)** 세션 구조
- ⛽ **연료 시스템** — 연료를 많이 채울수록 차가 무거워져 가속이 느려짐
- 🛞 **타이어 마모** — 코너링/브레이킹에 따라 마모되며, 약 3랩 주행 시 그립이 크게 저하됨
- 🚗 **AI 상대 차량 7대** + 차량 간 충돌 처리
- 📷 **1인칭 / 3인칭 카메라 전환**
- 🎨 PBR 머티리얼, 그림자, 안개, 하늘 등으로 구성된 3D 그래픽

## 로컬 실행 방법

브라우저 보안 정책(CORS) 때문에 `index.html`을 파일로 직접 열면 모듈 로딩이 실패합니다. 반드시 로컬 서버를 통해 실행하세요.

```bash
git clone <이 저장소 URL>
cd gt3-circuit

# 방법 1: Python
python3 -m http.server 8080

# 방법 2: Node (npx serve)
npx serve .
```

이후 브라우저에서 `http://localhost:8080` 접속.

**모바일 기기 테스트**: 기울기 센서는 `https` 환경 또는 `localhost`에서만 동작합니다 (iOS는 권한 요청 팝업이 추가로 뜹니다). 같은 와이파이의 폰에서 PC의 로컬 서버로 접속하려면 `ngrok` 등으로 HTTPS 터널을 열어야 iOS에서 센서 권한을 받을 수 있습니다.

## GitHub Pages로 배포하기

정적 파일이라 GitHub Pages에 바로 올릴 수 있습니다.

1. 이 저장소를 GitHub에 push
2. 저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 설정
3. `https://<username>.github.io/<repo>/` 에서 바로 플레이 가능 (HTTPS라 iOS 기울기 센서도 정상 동작)

## 프로젝트 구조

```
├── index.html          # 메인 UI (메뉴, HUD, 결과 화면 등)
├── package.json
├── src/
│   ├── main.js          # 게임 루프, 씬 구성, 세션(퀄리파잉/레이스) 흐름
│   ├── track.js          # 서킷 지오메트리 생성
│   ├── cars.js            # GT3 차량 스펙 목록
│   ├── vehicle.js        # 차량 3D 모델 + 물리 엔진(연료/타이어/충돌)
│   ├── ai.js               # AI 상대 차량 로직
│   └── input.js            # 기울기 센서 + 터치 입력 처리
└── vendor/three/         # Three.js 라이브러리 (CDN 없이 오프라인 동작용)
```

## 조작 방법

| 데스크톱 테스트용 | 방향키/WASD |

## 알려진 제한 사항

- 완전한 포토리얼리스틱 그래픽보다는 "괜찮은 수준"의 3D 그래픽을 목표로 제작되었습니다 (브라우저 WebGL 환경의 한계).
- 서킷은 실제 F1 트랙을 정확히 재현한 것이 아니라 F1 스타일 레이아웃에서 영감을 받은 자체 제작 트랙입니다.
- 차량 물리는 완전한 타이어 모델(슬립 앵글 등)이 아닌 트랙 좌표계 기반의 아케이드 물리로 구현되어 있습니다.
