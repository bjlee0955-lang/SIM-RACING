# APEX GT3 — Mobile SimRacing Prototype

Three.js 기반 모바일 심레이싱 게임 **프로토타입**입니다.
Unity/APK가 아닌 **웹(브라우저) 버전**으로, PC와 모바일 브라우저에서 바로 실행할 수 있습니다.

> ⚠️ **오리지널 콘텐츠 안내**: 이 프로젝트의 차량(Falcon GT3 / Wolf R EVO / Viper LMS)과 서킷(Ardennes Circuit)은
> 실제 브랜드·차량·트랙과 무관한 **창작 콘텐츠**입니다. 실제 F1 서킷이나 실제 자동차 제조사의 이름·로고·차량
> 디자인은 사용하지 않았습니다 (상표권 문제 회피).

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

모바일 기기에서 테스트하려면:

```bash
npm run dev -- --host
```

같은 Wi-Fi에 연결된 스마트폰 브라우저에서 `http://<PC의 IP>:5173` 접속 후,
메뉴의 **"자이로 권한 요청 (iOS)"** 버튼을 눌러 기울기 센서 권한을 허용하세요.
(Android/Chrome은 별도 권한 요청 없이 바로 동작합니다.)

## 빌드

```bash
npm run build
npm run preview
```

`dist/` 폴더에 정적 파일이 생성되며, GitHub Pages / Vercel / Netlify 등 어떤 정적 호스팅에도 배포 가능합니다.

## 구현된 기능

- **차량 3종** (Falcon GT3 / Wolf R EVO / Viper LMS) — 최고속도·가속·제동·코너링·무게 특성 차별화
- **오리지널 서킷 1개** (Ardennes Circuit) — 고저차 있는 스플라인 기반 트랙, 커브/배리어/숲 포함
- **자이로 조향** (`deviceorientation`) + 터치 가속/브레이크 + 조향 감도 조절 + 캘리브레이션
- **연료 시스템**: 랩 수가 아닌 **가속(스로틀) 시간에 비례**한 소비, 잔여 연료가 차량 무게에 영향
- **타이어 시스템**: 가속/제동/코너링/슬립 부하 기반 마모, 약 3랩 전후로 체감되는 그립 저하
- **차량 물리(근사 모델)**: 무게 이동, 그립, 관성, 오프트랙 페널티 등을 단순화된 아케이드-심 하이브리드로 구현
- **충돌 시스템**: 차량 간 근접 충돌 시 속도 감소 및 밀어내기
- **AI 차량 2대**: 레이싱 라인 유지, 코너 감속, 근접 시 회피/블로킹, 플레이어와 동일한 연료/타이어 규칙 적용
- **Qualifying(5분) / Racing(5랩)** 모드, 그리드/순위 계산
- **HUD**: 속도, 기어, RPM, 랩, 순위, 랩타임/베스트랩, 연료 게이지, 타이어 마모도, 미니맵
- **카메라 전환**: Cockpit(1인칭) / Chase(3인칭)

## 알려진 한계 (프로토타입 범위)

- Unity/APK가 아닌 웹 기반 구현이며, 네이티브 안드로이드 빌드는 포함되어 있지 않습니다.
- 차량 물리는 실제 타이어 모델/서스펜션 시뮬레이션이 아닌 근사 모델입니다.
- 사운드, 차량 손상 비주얼, 다중 트랙/차량은 아직 미구현입니다.
- AI 충돌 회피 및 추월 로직은 단순 규칙 기반입니다.

## 프로젝트 구조

```
├── index.html          # 진입점 (메뉴 / HUD / 결과 화면 DOM)
├── src/
│   ├── main.js          # 씬 구성, 게임 루프, 상태 관리, HUD
│   ├── vehicle.js        # 차량 물리 + 연료/타이어 시스템
│   ├── ai.js             # AI 컨트롤러
│   ├── input.js          # 자이로/터치/키보드 입력
│   ├── cars.js           # 차량/타이어/연료 스펙 데이터
│   ├── track.js           # 트랙 지오메트리 생성 (스플라인 기반)
│   └── style.css
├── package.json
└── vite.config.js
```
